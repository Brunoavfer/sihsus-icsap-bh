IRR = incidence rate ratio. Saneamento = % domicílios sem rede geral de água (Censo 2022). IVS = Índice de Vulnerabilidade Social (SMSA/PBH). Densidade real (hab/km²) calculada a partir dos polígonos oficiais de área de abrangência dos CS (PBH/SMSA). T1 (baixa densidade, ≤ 7.828 hab/km²): IRR = 0,943 (p<0,001) — associação significativa, confirmando a hipótese de confundimento ecológico. Em áreas pouco densas, pior saneamento coexiste com menor acesso hospitalar, produzindo menor registro de internações. T2 e T3 (densidade intermediária e alta): IRR não significativo (p>0,28). Interação saneamento×densidade (contínua): IRR = 1,014; p = 0,051 (marginalmente NS). Esses resultados sugerem que a associação observada no modelo geral é mediada pela concentração do efeito em áreas de baixa densidade, consistente com viés de acesso diferencial, mas análises adicionais com dados de utilização hospitalar são necessárias para confirmar o mecanismo.
